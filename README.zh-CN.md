# youyou-taobao-journal

把多年的淘宝购物记录整理成一份能翻、能打标、能回看的个人消费手账。助手负责启动页面、采集和续跑、核对商品实付、生成文章与保存记录，正常使用只需本人登录淘宝、给商品打使用标签。

这是 **0.1.0-trial 试用版**。已通过 46 项合成测试及页面检查，尚未用新的真实淘宝账号验证采集；首次真实运行由助手先检查少量页面字段，再继续批量处理。不承诺所有账号都能官方全量导出，也不承诺固定采集耗时。

## 一句话安装和使用

把完整仓库链接发给 Codex：

> 帮我安装 https://github.com/ruoruochen/youyou-taobao-journal ，分析我的10年淘宝消费记录。自动采集和续跑，保留原始数据和已有标签。

安装后可以直接说：“分析我的3年淘宝消费记录”或“继续补采我的消费手账”。使用完整链接安装，不依赖仅凭技能名字全网检索。

登录、验证码和系统安全授权必须由本人完成。助手不会要求你运行命令、逐页翻订单、准备 Excel，或另配模型 API 密钥。环境缺少必要浏览器能力时会明确说明，不会假装采集成功。

## 六个模块

- **消费总览**：按已核商品实付显示金额与覆盖范围。
- **消费档案馆**：按天回看花费，而不只是订单笔数。
- **买垃圾了吗**：默认先看已标低频的商品，按实付高低排序，自动计算低频部分金额；未打标的放后面。
- **幸福月报**：从每个月实际买到的物件里，写温暖、有趣的小文章，不编造使用经历。
- **消费人格**：自动匹配六个熟悉的影视人物之一，用简短有梗的卡片展示，仅供娱乐。
- **明年建议**：自动覆盖下一年 12 个月，每月安排 1—2 项可做的小任务，保留自己的修改和完成状态。

## 金额与采集规则

单商品优先使用明确记录的实付价，标价单独保留；未知金额不会当作 0，也不会拿父订单现金付款平均分摊。购物金充值不计消费，使用购物金购买的商品仍保留商品实付。关闭或交易状态待核的订单不进入消费统计。

采集按时间由近到远，不搜索订单，不调用私有接口或导出登录凭据。只在页面真实存在且能够识别时使用官方导出；否则自动翻页，仅给缺字段的订单补详情。脚本串行运行，出现频控、安全验证或本人接管时保存断点并停止。普通缺项记录到待核队列，不逐条打断用户。

## 环境与隐私

需要 **Codex、Python 3、Node.js 18+ 和已连接的 Ego 浏览器**。准备、启动与日常执行由助手处理；本试用版默认在本机运行，不是打开一个公共网页就能读取淘宝账号的云服务。

每个人的数据保存在技能目录之外的独立项目中。原始来源、图片、标签、月报与任务不会进入本仓库或技能安装包；不会自动上传、公开发布或改动已有手账站点。补采保留原件、稳定商品 ID 和已有标签，个人记录自动保存并支持历史恢复。

本仓库只包含可复用代码、页面模板和执行说明，不包含作者或其他人的订单、账号、地址、图片和标签。
