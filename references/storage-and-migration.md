# 保存与恢复

每个项目在当前工作区的 `taobao-journal/<random-project-id>/`，包含 project.json、journal.sqlite、raw、images、checkpoints、reports、backups。技能目录只有通用代码与模板。不要把个人项目提交仓库、附进技能zip或复制给新用户。

本机服务只监听127.0.0.1，随机端口；根页面发项目专用HttpOnly/SameSiteStrict会话，写请求检查Origin。没有外部CDN、遥测、默认上传或公共托管。关闭/重开助手后由start.py重新打开项目，不能依赖浏览器缓存保住标签。

个人记录采用schemaVersion3。所有标签、数量、分类/金额修正、月报修改、任务及完成状态写入SQLite，写前保存历史快照。界面收到确认才显示“已保存”，冲突按时间合并并保留历史；连接失败要显示未保存，提供重试和导出当前内存内容，不能装作成功。

导入只由用户选中或明确提供的个人记录；完整预览、稳定ID映射、冲突保留、导入前备份。重复导入不能叠加金额或复制任务。清除标签恢复待打标；删除任务/报告用归档并提供恢复入口。项目CLI `archive`/`restore`用于项目级软归档；不物理删除本人原件。

换账号：助手自动创建新项目，绝不沿用旧项目的订单或标签。账号一致性不能从聊天作者名称推断；只参考本次浏览器可见标记或清晰的新账号请求。无法验证续跑账号时先隔离新项目，不能猜合并。

跨设备默认没有云同步。若用户要求部署，先选择能隔离用户、保存写入和访问控制的方式；公共静态网站不能直接承载私人完整订单。另行部署必须生成新站点，不操作任何现有手账或账号站点。
